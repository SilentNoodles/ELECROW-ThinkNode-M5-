# Glossary

## Base Station

A planned NCTNL node role providing higher-level services. The detailed implementation is still under development.

## Field Node

The primary portable/user-facing NCTNL node role. The ELECROW ThinkNode M5 is the current main development platform.

## Meshtastic

The underlying LoRa mesh firmware and ecosystem on which NCTNL is built.

## NCTNL

The project-specific extension layer built on Meshtastic.

## NctnlEvent

The current protobuf structure used as the foundation for machine-readable NCTNL events.

## PRIVATE_APP

A Meshtastic application PortNum currently used by the experimental structured NCTNL event path.

## Quick Message

A predefined human-readable operational message selected from the NCTNL Quick Message Menu.

## Relay Node

A planned NCTNL node role. Detailed behaviour is not yet final.

## Status Message

The existing Meshtastic feature reused by NCTNL for the four-part NCTNL status string.

## TEXT_MESSAGE_APP

The normal Meshtastic application path used for human-readable text messages, including current NCTNL predefined Quick Messages and Send Coordinates.
